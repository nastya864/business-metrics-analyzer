# Ответы на контрольные вопросы

## 1. Чем отличается Git от GitHub?

Git — это система контроля версий, которая хранит историю изменений проекта и позволяет работать с ветками.

GitHub — это облачная платформа для хранения Git-репозиториев и совместной работы разработчиков.

## 2. Для чего используется виртуальное окружение Python?

Виртуальное окружение создаёт изолированную среду для проекта. Оно позволяет устанавливать нужные библиотеки отдельно от других проектов и системного Python.

## 3. Что такое commit, branch, remote и pull request?

- Commit — зафиксированное изменение проекта в истории Git.
- Branch — отдельная ветка разработки.
- Remote — удалённый Git-репозиторий, например репозиторий на GitHub.
- Pull Request — запрос на проверку и объединение изменений из одной ветки в другую.

## 4. Зачем нужен файл .gitignore?

Файл `.gitignore` указывает Git, какие файлы и папки не нужно добавлять в репозиторий. Например, `.venv`, `__pycache__`, временные файлы и настройки IDE.

## 5. Как организовать командную работу с помощью Git?

Разработчики клонируют общий репозиторий и создают отдельные ветки для своих задач. После выполнения работы разработчик создаёт commit, отправляет ветку на GitHub и оформляет Pull Request. Другой участник проверяет изменения и выполняет merge в `main`.

## 6. Какие файлы должны быть в репозитории учебного проекта?

В репозитории должны находиться:

- `main.py`;
- `README.md`;
- `requirements.txt`;
- `.gitignore`;
- документация в папке `docs`.

Папку `.venv` добавлять в репозиторий не нужно.

## 7. Что произойдёт, если два разработчика изменят один файл в разных ветках?

Если изменены разные строки, Git обычно объединит изменения автоматически. Если изменены одни и те же строки, возникнет конфликт слияния. Разработчики должны разрешить его вручную, проверить код и сохранить исправление новым commit.
