# Описание ключевых Use Cases

## UC-02. Формирование отчёта

| Поле | Значение |
|---|---|
| Название | Формирование отчёта |
| Основной актор | Аналитик |
| Цель | Получить отчёт с KPI за выбранный период |
| Предусловия | Пользователь авторизован; данные о продажах загружены |
| Триггер | Аналитик выбирает команду «Сформировать отчёт» |
| Основной поток | 1. Аналитик открывает раздел отчётов. 2. Выбирает период. 3. Запускает формирование. 4. Система рассчитывает KPI. 5. Система отображает отчёт. |
| Альтернативный поток | Если данных за период нет, система сообщает об этом и не формирует фиктивные показатели |
| Постусловия | Отчёт доступен для просмотра и последующего экспорта |

## UC-03. Загрузка данных о продажах

| Поле | Значение |
|---|---|
| Название | Загрузка данных о продажах |
| Основной актор | Менеджер по продажам |
| Цель | Передать системе исходные данные для расчёта KPI |
| Предусловия | Пользователь авторизован и имеет право загрузки |
| Триггер | Пользователь выбирает CSV- или Excel-файл и запускает импорт |
| Основной поток | 1. Система принимает файл. 2. Проверяет формат и обязательные поля. 3. Сохраняет корректные записи. 4. Показывает результат импорта. |
| Альтернативный поток | При ошибке формата или данных импорт отклоняется с перечнем ошибок |
| Постусловия | Корректные данные сохранены и доступны для расчёта KPI |
