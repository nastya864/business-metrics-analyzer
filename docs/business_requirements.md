# Бизнес-требования к приложению Business Metrics Analyzer

## 1. Назначение системы

Приложение предназначено для расчёта и анализа ключевых показателей эффективности предприятия на основе финансовых данных.

## 2. Бизнес-цель

Автоматизировать обработку данных о выручке и затратах предприятия, чтобы ускорить оценку результатов деятельности и снизить вероятность ошибок при ручных расчётах.

## 3. Пользователи системы

Основные пользователи:

- бизнес-аналитик;
- финансовый специалист;
- руководитель предприятия.

## 4. Входные данные

Для расчётов используются:

- месяц;
- выручка предприятия;
- себестоимость или затраты.

## 5. Функциональные требования

Приложение должно:

- обрабатывать исходные финансовые данные;
- рассчитывать среднюю выручку;
- рассчитывать прибыль;
- рассчитывать рентабельность;
- выводить результаты пользователю;
- поддерживать добавление новых метрик и визуализаций.

## 6. Нефункциональные требования

Приложение должно:

- работать на Python 3.10 или новее;
- использовать библиотеки `pandas` и `matplotlib`;
- запускаться по инструкции из `README.md`;
- хранить зависимости в `requirements.txt`;
- не хранить `.venv` и временные файлы в репозитории.

## 7. Ожидаемый результат

Пользователь получает таблицу исходных данных, среднюю выручку и рассчитанную рентабельность предприятия.
